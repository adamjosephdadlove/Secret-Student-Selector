SECRET STUDENT SELECTOR:
A nice web app made to manage lists and randomly pick winners.

Live Demo:
https://adamjosephdadlove.github.io/Secret-Student-Selector/

Features:
• Smart Input: Automatically splits and cleans names typed with commas.
• Save & Clear: Saves your list to the browser memory or clears it instantly.
• Card View: Displays entries in neat layout cards with quick delete buttons.
• Randomizer: Selects a single winner completely at random.

Built With:
HTML5 / CSS3 / JavaScript
